# まるごとスクショ

開いているウェブページを、上から下まで1枚の画像やPDFとして保存するChrome拡張機能です。
無料で、広告もアカウント登録もありません。

---

## 作った理由

長く使われていた全画面キャプチャの拡張機能が、2026年8月10日ごろにChromeウェブストアから消えました。
利用者は1100万人を超えていたそうです。開発元は著作権まわりの申し立てによる一時的なもので、復活に向けて交渉中だと説明しています。

毎日の作業で使っていた道具が、ある朝いきなり使えなくなる。
同じことは他のツールでも起こります。それなら自分の手元に置けるものを1つ持っておこうと考えて、一から書きました。

---

## できること

ボタンを1回押すだけで、ページの端から端までを自動で撮ります。

- 縦に長いページを、継ぎ目のない1枚の画像につなぎ合わせる
- PNG、JPEG、PDF（A4に分割）、PDF（長い1枚）の4通りで保存
- クリップボードへ直接コピーして、資料にそのまま貼り付ける
- 画面に貼り付いて動くヘッダーやフッターを、2枚目からは隠す
- あとから読み込まれる画像を先に表示させてから撮るため、白い抜けが起きにくい
- ページ本体ではなく、中の枠だけがスクロールする作りのサイトにも対応

---

## 入れ方

Chromeウェブストアには出していません。開発者モードで、フォルダを直接読み込ませて使います。

1. このページの緑色の「Code」ボタンから「Download ZIP」を選び、パソコンに保存する
2. 保存したZIPファイルを展開する（右クリックから「すべて展開」）
3. Chromeのアドレス欄に `chrome://extensions` と入れて開く
4. 画面の右上にある「デベロッパー モード」のスイッチをオンにする
5. 左上に出てくる「パッケージ化されていない拡張機能を読み込む」を押す
6. 展開したフォルダの中の **`extension`** フォルダを選ぶ（`manifest.json` が入っている階層）

一覧に「まるごとスクショ」が出れば完了です。
最後にChromeの右上のパズルのピースのマークを押して、ピンを留めておくとボタンが常に出ます。

> 展開したフォルダは消さずに置いておいてください。Chromeはそのフォルダを読みに行き続けます。

## 使い方

撮りたいページを開いて、ツールバーのアイコンを押すだけです。

- アイコンを押す（キーボードの `Alt` ＋ `Shift` ＋ `S` でも動きます）
- ページが自動で下までスクロールし、アイコンに `3/8` のような進み具合が出る
- 撮り終わると、新しいタブで結果の画面が開く

撮っている間は、そのタブを開いたままにしておきます。
別のタブへ切り替えると途中で止まります。違うページが写り込むのを防ぐためです。

### 保存の種類

| ボタン | 中身 | 向いている場面 |
|---|---|---|
| 画像で保存（きれい） | PNG形式。文字がくっきり | 資料に貼る、記録として残す |
| 画像で保存（軽い） | JPEG形式。容量が小さい | メールやチャットで送る |
| PDFで保存（用紙サイズに分ける） | A4の紙に切り分けたPDF | 印刷する、取引先に渡す |
| PDFで保存（長い1枚） | 縦に長いままのPDF | 画面で通して読んでもらう |

## 設定

アイコンを右クリックして「オプション」を選ぶか、結果画面の「設定を開く」から開けます。

- 撮る前に一度ページの下まで流す（あとから出てくる画像を読み込ませる。初期はオン）
- 2枚目からは追従するヘッダーやフッターを隠す（初期はオン）
- 1枚撮るごとの待ち時間（初期は450ミリ秒）
- 撮り終わったら自動で保存する（初期はオフ）

## うまくいかないときは

サイトの作りによっては崩れることがあります。症状ごとの直し方をまとめました。

**上のメニューが何度も重なって写る**
設定の「追従するヘッダーやフッターを隠す」がオフになっていないか見てみてください。

**画像の一部が白く抜ける**
設定の「撮る前に一度ページの下まで流す」をオンにして、「画面が落ち着くまでの待ち時間」を500ミリ秒くらいに伸ばすと直ることが多いです。

**途中で止まる、または同じ画面が続けて写る**
「1枚撮るごとの待ち時間」を700〜1,000ミリ秒に伸ばしてみてください。
Chromeには1秒間に撮れる回数の決まりがあり、そこに引っかかっている状態です。

**撮れないページがある**
`chrome://` で始まる設定画面、拡張機能の管理画面、Chromeウェブストアは、Chrome側の決まりで撮影できません。回避する方法はありません。

**ページが長すぎるとき**
画像として作れる大きさに限りがあるため、自動で縮めて保存します。何％に縮めたかは結果画面に出ます。

## 求める権限について

この拡張機能が求める権限は `activeTab`、`scripting`、`storage` の3つだけです。

`activeTab` は「アイコンを押した、その瞬間のタブ」にしか効きません。
普段はどのページも読み取れず、閲覧履歴も集めません。撮った画像が外部へ送られることもなく、処理はすべてパソコンの中で完結します。

## 中身

外部のライブラリは1つも使っていません。Manifest V3で書いています。

| ファイル | 役割 |
|---|---|
| `manifest.json` | 拡張機能の名札。権限や入口を書いている |
| `background.js` | 全体の進行役。撮る位置を決めて、画面を1枚ずつ取り込む |
| `capture.js` | ページ側の担当。指示された位置までスクロールして、追従要素を隠す |
| `result.html` / `result.js` | 結果画面。断片を1枚につなぎ、画像やPDFとして書き出す |
| `pdf.js` | PDFの組み立て。JPEGを貼っただけの素直なPDFを自前で書いている |
| `options.html` / `options.js` | 設定画面 |
| `make_icons.py` | アイコンを作り直すスクリプト。Python標準の機能だけで動く |
